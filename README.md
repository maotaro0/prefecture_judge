## アプリケーション名

  都道府県ジャッジ

## アプリケーション概要

「都道府県ジャッジ」は、複数の候補県の中から、ヒントと該当数をもとに隠された正解の都道府県を推理するゲームです。

「海に面している：2 / 3県」のような情報を組み合わせながら候補を絞り込み、都道府県の知識だけでなく、論理的に考える過程も楽しめる推理型のクイズゲームを目指しています。

## 利用方法

1. トップページからゲームを開始します。
2. 47都道府県の中から、候補となる10県がランダムに表示されます。
3. 表示されたヒントと、正解3県のうち何県がその条件に該当するかを確認します。
4. 必要に応じて「次のヒント」から新しいヒントを確認します。
5. 候補10県の中から、正解だと思う3県を選択して回答します。
6. リザルト画面で、正解・不正解、自分の回答、正解だった3県を確認します。
7. 「もう一度遊ぶ」から新しいゲームを開始できます。


## アプリケーションを作成した背景

ちょっとした休憩時間や余暇などの隙間時間に、気軽に楽しみながら考えることのできるゲームを作りたいと考え、このアプリケーションを制作しました。

一般的な都道府県クイズは、一問一答形式で知識を問うものが多く、知っているかどうかで答えが決まるものが中心です。

そこで本アプリケーションでは、「海に面している：2 / 3県」のようなヒントと該当数を手掛かりに、複数の情報を組み合わせながら正解を絞り込むゲーム形式を採用しました。

限られた情報から条件を整理し、「この県が正解ではないか」と仮説を立てながら推理することで、都道府県に関する知識だけでなく、考える過程そのものを楽しめるアプリケーションを目指しています。

また、本アプリケーションの制作を通して、データベース設計、ゲームロジック、JavaScriptによる画面操作、UI改善など、Webアプリケーション開発の一連の流れを経験することも目的としています。


## 実装した機能

- 47都道府県から候補10県をランダムに選出する機能
- 候補10県の中から正解3県をランダムに決定する機能
- 都道府県データをもとにヒントと該当数を表示する機能
- 表示済みのヒントを残しながら、次のヒントを追加する機能
- 候補10県から3県を選択し、3県選択時のみ回答できる機能
- 選択した3県と正解3県を比較する正誤判定機能
- リザルト画面で自分の回答と正解を確認する機能
- 再プレイ・トップページへ戻る機能
- スマートフォン向けのレスポンシブ対応


## 実装予定の機能

- 人口・面積・気候など、ヒントに使用する都道府県データの追加
- 不正解後もヒントを確認しながら再回答できる機能
- 過去の回答と正解数を確認できる履歴機能
- ゲーム途中で終了できるギブアップ機能
- 中級・上級の難易度選択機能
- ヒントの有用性を考慮した出題ロジックの改善
- UI・操作性の改善
- コードのリファクタリング、自動テストの追加、本番環境へのデプロイ


## 工夫したポイント

### 1. 毎回異なる問題を生成するゲーム設計

固定された問題を順番に解くのではなく、ゲーム開始時に47都道府県から候補10県をランダムに選び、さらにその中から正解3県を決定する仕組みにしました。

これにより、プレイするたびに異なる都道府県の組み合わせが生成され、繰り返し遊べるゲームを目指しています。


### 2. ヒントと「該当数」を組み合わせた推理システム

都道府県の特徴をそのままヒントとして表示するだけではなく、

「海に面している：2 / 3県」

のように、正解3県のうち何県がその条件に該当しているかを表示する仕組みを実装しました。

複数のヒントと数字を組み合わせながら候補を絞り込むことで、知識だけではなく論理的な推理も楽しめるようにしています。


### 3. ゲーム状態と正解判定をRails側で管理

候補となる都道府県、正解となる都道府県、表示済みのヒントなどのゲーム状態を `session` を利用して管理しています。

また、正解となる都道府県の情報をブラウザ側で判定するのではなく、ユーザーが選択した都道府県と正解をRails側で比較して正誤判定を行う構成にしています。

これにより、画面表示とゲームロジックの役割を分けることを意識しました。
